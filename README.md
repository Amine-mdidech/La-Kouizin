# 🍳 La Kouizin

La Kouizin is an app that helps users save and organize their favorite recipe and cooking videos from YouTube, Instagram, and TikTok — all in one place.

Whether you're a home cook, food content creator, or just someone who loves experimenting in the kitchen, KitchenClips is your go-to tool for building a personal, searchable, and organized library of cooking inspiration.

---

## 🚀 Features

- 🔗 **Multi-Platform Support**: Save videos from YouTube, Instagram, and TikTok
- 📂 **Smart Organization**: Categorize videos by type (e.g., breakfast, beverages, desserts ...)
- 📝 **Custom Notes**: Add personal notes, tweaks, and ingredients
- 🔍 **Searchable Library**: Quickly find saved videos by title, tags, or ingredients
- 🧑‍🍳 **Video Game like graphics**: Cute, retro like ingredients and many more coming soon
